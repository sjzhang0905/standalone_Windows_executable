# standalone_Windows_executable

A collection of standalone Windows utilities for computational chemistry, structure processing, data analysis, and scientific visualization.

The tools in this repository are distributed as precompiled Windows executables. Source code is not included.

## Download

Precompiled executables are available from the **Releases** section of this repository.

Most tools are standalone Windows applications and do not require a separate Python installation.

## Tools

This repository may contain utilities for tasks such as:

CarbonStructureBuilder
石墨烯、碳纳米管构建工具

ChemStructConverter
各类格式转换工具

HeterostructureBuilder
异质结构建工具

MetalSlabBuilder
金属单质表面构建工具

PDFMergeStudio
各类文件合并为pdf工具

The exact set of available tools may change over time. See the **Releases** section for currently available programs.

## Maintenance

New tools may occasionally be added to this repository.

Existing tools, however, should generally be considered feature-complete and are unlikely to receive regular updates. Updates will normally only be made when a serious bug is discovered or when a change is necessary to keep a tool functional.

Therefore, this repository should not be expected to follow a regular release or maintenance schedule.

## Platform

Unless otherwise noted:

- Windows 10 / Windows 11
- 64-bit
